# Demo pack

Prepare a `demo/` folder or README section that lets a grader understand the system in five minutes.

1. **Problem and boundary** — one sentence plus diagram.
2. **Contract** — OpenAPI version, primary endpoint, and provider/consumer relationship.
3. **Run** — clean-clone commands and required configuration; no secret values.
4. **Verify** — health request, one happy-path request, one expected failure, and test-report location.
5. **Integration** — dependency topology, contract version, and handshake result.
6. **Evidence and limitations** — paths to reports/screenshots and honest known issues.

Record the Git commit SHA used for the demo. A live service is optional evidence; the repository must still stand on its own.

## Bản dịch tiếng Việt

Demo pack cần nêu bài toán/boundary, contract, lệnh chạy clone sạch, health và request kiểm chứng, tích hợp, đường dẫn evidence và giới hạn. Ghi commit SHA dùng để demo; service live chỉ là minh chứng bổ sung, repository vẫn phải tự đủ để chấm.
