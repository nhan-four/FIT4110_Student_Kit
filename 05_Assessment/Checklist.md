# Cross-lab checklist

- [ ] I can state why the service exists and what it does not own.
- [ ] The API contract is explicit and linted.
- [ ] A consumer can test without waiting for the real provider.
- [ ] Tests include success, invalid input, boundary, and health behavior.
- [ ] The service runs in Docker and is tested there.
- [ ] Compose documents dependencies, configuration, and health checks.
- [ ] A clean clone has a runnable README and evidence.
- [ ] My submitted URL is public and points to the intended final commit.
