# Submission

## Final checklist

1. Run the lab’s verification commands from a clean terminal.
2. Complete the lab checklist and known-issues record.
3. Confirm no secrets or local-only files are tracked: `git status` and `git ls-files`.
4. Push your latest commit to your one personal **public** GitHub repository: `FIT4110_<MãSinhViên>`.
5. Confirm that the current lab is in its required top-level folder and that earlier labs remain intact.
6. Open the repository URL in a logged-out/private window if possible and confirm that the intended portfolio is visible.
7. Paste this same repository URL into the course Google Sheet before the deadline.

The single submitted URL identifies the whole semester portfolio. Do not replace repository history after submission without instructor permission. Keep generated reports, screenshots, and run instructions in the repository as part of your evidence.

## Bản dịch tiếng Việt

Trước khi nộp, chạy lại lệnh kiểm tra của Lab, hoàn thành checklist/known issues, kiểm tra không có secret và push commit mới nhất lên repository public duy nhất `FIT4110_<MãSinhViên>`. Bảo đảm Lab hiện tại nằm đúng thư mục, các Lab cũ còn nguyên và repository hiển thị được mà không cần cấp quyền. Nộp URL theo hướng dẫn của học phần. URL đó đại diện cho toàn bộ portfolio học kỳ; không rewrite lịch sử sau khi nộp nếu chưa được giảng viên cho phép.
