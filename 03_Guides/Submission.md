# Submission

## Final checklist

1. Run the lab’s verification commands from a clean terminal.
2. Complete the lab checklist and known-issues record.
3. Confirm no secrets or local-only files are tracked: `git status` and `git ls-files`.
4. Push your latest commit to your personal **public** GitHub repository.
5. Open the repository URL in a logged-out/private window if possible; the grader must be able to download a ZIP.
6. Paste the exact repository URL into the course Google Sheet before the deadline.

The submitted URL identifies the version to grade. Do not replace repository history after submission without instructor permission. The instructor downloads the repository ZIP; absent generated reports, screenshots, or run instructions are therefore missing evidence.
