# Lab 06 — Integration and Plug-a-thon

**Goal:** demonstrate that independently built services can integrate through agreed contracts.

Before the event, freeze the API version, nominate provider/consumer contacts, prepare a clean-clone run guide, and complete [the negotiation log](../04_Templates/negotiation-log-template.md). During integration, record the exact endpoint, environment, contract version, request/response evidence, defects, owner, and decision.

Success means more than a live demo: another team can reproduce the connection, diagnose failures from your documentation, and see which contract version was used. Package the result using [DemoPack](../05_Assessment/DemoPack.md).
